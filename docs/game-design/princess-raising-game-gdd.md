## 0. 한 줄 피치

**"8년 동안 한 아이를 키운다. 당신의 선택이 아이의 인생이 되고, 아이의 인생이 당신을 바꾼다."**
프린세스메이커의 핵심 재미(스케줄 배분 → 능력치 성장 → 다양한 엔딩)를 계승하되, **'아이의 자율성'**과 **'부모의 서사'**를 더해 현대적으로 재해석한 육성 시뮬레이션.

---

## 1. 비전 & 디자인 필라

### 1.1 왜 지금 이 게임인가
- 프린세스메이커 2 리제네레이션(2023) 흥행으로 장르 수요가 재확인됨. 그러나 신작은 대부분 '복각'에 머묾.
- 코어 팬은 "내가 키운 결과가 눈에 보이는 것"을 원하고, 신규 유저는 "노가다·반복 스케줄 돌리기"를 지루해함.
- 기회: **장르의 뼈대는 유지하고, 반복의 피로를 낮추고, 감정 서사를 강화**한 작품은 아직 없음.

### 1.2 디자인 필라 (모든 의사결정의 기준)
| # | 필라 | 설명 | 반(反)패턴 |
|---|------|------|-----------|
| P1 | **선택이 흔적을 남긴다** | 모든 스케줄·대화·소비가 능력치·성격·관계·외형·엔딩 중 최소 2곳에 영향 | 아무 영향 없는 장식 선택지 |
| P2 | **아이는 인형이 아니다** | 아이는 자기 의지(성격·욕구)를 갖고 때로 거부·제안·반항한다 | 100% 명령대로 움직이는 캐릭터 |
| P3 | **반복은 짧게, 변화는 크게** | 월 단위 스케줄 루프는 60초 이내로 끝나고, 분기마다 눈에 띄는 변화(외형·이벤트·대사) 발생 | 같은 화면 100번 보기 |
| P4 | **엔딩은 '등급'이 아니라 '삶'이다** | 여왕 엔딩이 농부 엔딩보다 "우월"하지 않다. 각 엔딩은 고유 에필로그와 후일담을 가진다 | 능력치 총합 순 랭크 엔딩 |
| P5 | **부모도 성장한다** | 플레이어 캐릭터(보호자)에게도 서사·능력·결말이 있다 | 얼굴 없는 UI 조작자 |

### 1.3 타깃
- **코어**: 30~45세, 프린세스메이커·동급생·토키메키 세대. 향수 + "제대로 만든 신작"을 원함.
- **확장**: 20~35세, 스타듀밸리·하베스트문·코지 게임 유저. 느긋하고 따뜻한 서사 선호.
- **플레이 세션**: 1회 20~40분(인게임 1년) / 1회차 완주 6~8시간 / 다회차 설계.

## 2. 코어 루프

```
[월초] 스케줄 편성 (3슬롯: 상순·중순·하순)
   ↓
[월중] 자동 진행 + 랜덤/조건 이벤트 발생 (아이의 제안·거부 포함)
   ↓
[월말] 결산: 능력치·성격·체력·스트레스·금전 변동, 외형 변화, 대화 1회
   ↓
[분기] 큰 이벤트: 수확제·무도회·시험·여행·가족 사건
   ↓
[연말] 생일 → 성장 단계 전환, 연간 리포트, 보호자 선택지(1년에 1번 큰 방향 결정)
   ↓
8년 반복 → 18세 생일 → 엔딩 결정 → 에필로그 → 후일담 모드
```

**세션 리듬 목표**: 1개월 = 60~90초, 1년 = 15~20분. 이벤트 밀도는 연평균 월 1.5회(완전 무이벤트 월은 연속 2회 이상 금지).

## 3. 세계관 & 설정

### 3.1 세계: 「셀레스티아 왕국」
- 세 개의 달이 뜨는 중세 판타지 왕국. 100년에 한 번 '별의 아이'가 떨어진다는 전설.
- 왕국은 ①왕도(정치·귀족) ②항구도시(상업·모험) ③농촌 평원(생활·마법) 세 지역으로 나뉘며, 아이의 진로가 지역과 연결됨.
- 분위기 톤: 따뜻하되 가볍지 않음. 어둠(전쟁 전조, 계급, 질병)은 존재하지만 극단 묘사 없음(12세 이용가 목표).

### 3.2 주인공 (보호자 = 플레이어)
- 전직 왕실 기사 또는 떠돌이 학자 중 선택 → 초기 재산·인맥·가능한 아르바이트·일부 이벤트 분기 결정.
- 보호자 스탯: **신뢰(아이와의 관계)**, **평판**, **재력**, **건강**. 보호자가 과로하면 아이 이벤트에 영향(P5).

### 3.3 아이 (딸)
- 10세 생일에 '별똥별과 함께 나타난 아이'로 맡게 됨(기본 설정). 출생의 비밀은 메인 서사의 축.
- 이름·머리색·눈색 커스터마이즈. 성격은 **초기 랜덤 + 양육으로 변동**(아래 4.3).

### 3.4 주요 NPC (관계 수치 보유)
| 이름 | 역할 | 서사 기능 |
|------|------|-----------|
| 큐브 | 집사 요정(마스코트) | 튜토리얼·조언·유머·세이브 안내 |
| 마담 로렌 | 왕도 예절학교 교장 | 귀족 루트 게이트키퍼 |
| 가렛 | 항구 용병단장 | 모험·전투 루트, 보호자의 과거와 연결 |
| 엘다 | 평원의 약초 마법사 | 마법·치유 루트, 아이의 출생 비밀 열쇠 |
| 리온 | 동년배 소년(왕자? 평민?) | 우정/연애 서브플롯(연애는 16세 이후만 해금) |
| 테오도라 | 라이벌 소녀 | 분기별 경쟁 이벤트, 성장 비교 거울 |

## 4. 핵심 시스템

### 4.1 능력치 (12종, 0~999)
| 범주 | 능력치 | 주요 상승 수단 |
|------|--------|---------------|
| 신체 | 체력, 근력, 민첩 | 농장일·검술·무도 |
| 지성 | 지식, 교양, 마력 | 학교·가정교사·마법수업 |
| 사교 | 매력, 예절, 화술 | 예절학교·무도회·접객 아르바이트 |
| 내면 | 감수성, 신앙, 도덕 | 예술·성당·봉사·대화 선택 |

- 파생치: **스트레스(0~100)**, **피로**, **용돈 만족도**, **악평(비행 누적)**.
- 능력치는 **서로 견제**: 근력↑ 시 매력 미세↓(설정상 '거칠어짐'), 마력↑ 시 신앙 미세↓ 등. 트레이드오프가 빌드 다양성을 만든다.

### 4.2 스케줄 (월 3슬롯)
- **교육(8종)**: 일반학교, 예절학교, 검술도장, 마법탑, 예술원, 신학교, 상업학원, 농업학교
- **아르바이트(10종)**: 농장, 식당, 여관, 교회, 재봉, 대장간, 성 청소, 묘지기(야간·위험), 상점 점원, 극단 단역
- **자유행동**: 휴식(스트레스↓), 모험(랜덤 던전, 전투 미니게임), 쇼핑, 친구와 외출, **아이 자율행동**
- 각 활동은 **숙련도(Lv.1~5)**를 가져 반복 시 효율↑ + 상위 이벤트 해금 (반복에 보상을 주되 P3 위반 안 하도록 Lv.3부터 자동 요약 모드 제공).

### 4.3 성격 시스템 (P2의 핵심) — 5축 성격 벡터
| 축 | 양극 ↔ 음극 | 영향 |
|----|------------|------|
| 외향 | 활발 ↔ 내성 | 사교 이벤트 발생률, 친구 수 |
| 순응 | 온순 ↔ 반항 | 스케줄 거부 확률, 자율행동 빈도 |
| 야심 | 야망 ↔ 소박 | 상위 직업 엔딩 가중치, 스트레스 민감도 |
| 감성 | 낭만 ↔ 현실 | 예술/연애 이벤트, 금전 감각 |
| 선악 | 정의 ↔ 교활 | 도덕 이벤트 분기, 악역 엔딩 해금 |

- 성격은 **플레이어가 직접 조작 불가**. 스케줄·대화·소비 패턴의 누적 결과로만 변함.
- **거부 시스템**: 순응이 음극이거나 스트레스 70+면 아이가 스케줄을 거부/대체 제안. 플레이어는 ①수용 ②설득(화술·신뢰 판정) ③강행(신뢰↓·스트레스↑) 중 선택.
- **자율행동**: 월 1슬롯을 아이에게 맡기면 성격에 따라 스스로 활동 선택 → 예상 밖 능력치·숨은 이벤트(비밀 친구, 몰래 모험 등) 발생. "통제 vs 신뢰"의 긴장감이 게임의 정서적 핵.

### 4.4 성장 단계 & 외형
| 연령 | 단계 | 변화 |
|------|------|------|
| 10~11 | 유년기 | 스케줄 효율 낮음, 이벤트는 가족·일상 중심 |
| 12~13 | 소녀기 | 학교 라이벌·친구 등장, 외형 1차 변화 |
| 14~15 | 사춘기 | 거부·반항 피크, 자율행동 중요, 외형 2차 변화 |
| 16~17 | 청년기 | 진로 이벤트 집중, 연애 서브플롯 해금, 엔딩 복선 |
| 18 | 성인 | 엔딩 |

- 외형은 **능력치·성격·직업 복장**이 반영되는 레이어드 스프라이트(머리·눈·체형·의상·소품·표정). 근력 높으면 자세가 당당, 교양 높으면 자세가 우아 등 '보이는 성장'(P1).

### 4.5 경제
- 수입: 보호자 연금(초기 직업별) + 아르바이트 + 이벤트 보상.
- 지출: 수업료, 식비(체력 유지), 의상·소품(매력·이벤트 조건), 가정교사, 선물(관계).
- 설계 목표: **항상 약간 부족하게**. 모든 걸 다 할 수 없게 하여 선택이 생기도록. 중반(13~15세)에 '큰 지출 이벤트'(병·사고·초대장)로 자금 압박 1회.

### 4.6 이벤트 시스템
- 구성: 고정 이벤트(연 4회 분기 축제) + 조건 이벤트(능력치·성격·관계 임계치) + 랜덤 이벤트(계절 가중치) + 연쇄 이벤트(3~5단계 미니 스토리라인 12개).
- 선택지는 **최소 2개, 최대 4개**, 선택 후 결과 즉시 확인 가능(숨은 변동은 월말 결산에 아이콘으로 암시).
- 목표 물량: 출시 시 **텍스트 이벤트 400개 이상**, 연쇄 스토리라인 12개, 엔딩 전용 이벤트 60개.

### 4.7 미니게임(선택적, 스킵 가능)
- 모험(턴제 간이 전투, 3~5턴), 요리(타이밍), 무도회(리듬), 시험(퀴즈 아닌 '집중력 게이지').
- 모두 **자동 해결 옵션** 제공(P3). 미니게임은 보너스 보상용이지 진행 필수 아님.

### 4.8 엔딩 (출시 목표 40종 + 히든 8종)
- 결정 로직: **직업 적합도(능력치) × 성격 가중 × 관계 트리거 × 서사 플래그**의 복합 점수. 최고 점수 직업이 엔딩, 2위는 에필로그에 "다른 길이었다면" 암시.
- 카테고리:
  - 왕실/정치: 여왕, 공작부인, 외교관, 재상
  - 무예: 근위기사단장, 용병왕, 모험가, 현상금 사냥꾼
  - 학문/마법: 대마법사, 왕실학자, 연금술사, 약초의사
  - 예술/문화: 궁정악사, 극단 스타, 화가, 작가
  - 생활/상업: 대상인, 농장주, 요리사, 여관 주인
  - 신앙: 대주교, 성녀, 순례자
  - 어둠: 암살자, 도적단 두목, 사기꾼 (선악 음극 + 악평)
  - 관계: 결혼(리온/기타), 가업 승계, 보호자와 평생 동거(가정 엔딩)
  - 히든: 별의 여신(출생 비밀 완결), 세계 여행자, 시간 역행 등
- **에필로그는 2단**: ①10년 후 장면 ②보호자와의 마지막 대화 → 그리고 **후일담 모드**(엔딩 후 아이가 편지를 보내오는 저빈도 콘텐츠).

### 4.9 메타 진행 (다회차)
- 2회차부터: 이전 엔딩 '별 조각' 획득 → 새 초기 직업/이벤트/의상/시작 보너스 해금.
- **엔딩 앨범 + 성격 지도**: 어떤 선택이 어느 엔딩에 가까워졌는지 사후 시각화(P1 강화).
- **유산 시스템**: 이전 회차의 딸이 다음 회차 NPC로 카메오 등장(랜덤 1명).

## 5. 서사 설계

### 5.1 메인 플롯 (3막)
- **1막 (10~12세) 만남**: 별똥별 소녀를 맡게 됨. 마을 적응, 큐브와의 생활, 첫 생일.
- **2막 (13~15세) 균열**: 아이의 출생을 아는 자들의 접근(왕실·마법탑·교단). 아이의 정체성 혼란, 반항. 보호자의 과거가 드러남.
- **3막 (16~18세) 선택**: 아이가 '별의 아이'로서의 운명을 받아들일지, 평범한 삶을 택할지. 플레이어 선택이 아니라 **아이의 성격 벡터가 결정**하고, 플레이어는 그것을 받아들이거나 마지막까지 개입하려 함.

### 5.2 정서적 목표
- 플레이어가 중반에 "내가 너무 몰아붙였나?"라고 스스로 묻는 순간을 **설계로 만든다** (예: 15세 생일, 아이가 평소 스케줄 패턴을 언급하며 속마음을 말하는 이벤트. 패턴별 대사 20종 이상).
- 엔딩 직전 '마지막 대화'는 8년의 기록을 요약한 **데이터 기반 대사**("엄마는 내가 열두 살 봄에 처음 검을 쥐었을 때…")로 생성.

### 5.3 톤 & 금지선
- 로맨스는 16세+ 동년배 NPC 한정. 보호자-아이 연애 **금지**.
- 폭력·비행 이벤트는 결과(관계 악화, 악평)로 묘사. 선정성 없음.

## 7. 기술 설계 요약

### 7.1 엔진 & 아키텍처
- **Godot 4 (GDScript + C#)** 권장: 2D 특화, 라이선스 비용 0, 모바일 포팅 용이. (대안: Unity)
- 데이터 드리븐: 모든 이벤트·스케줄·엔딩은 **JSON/YAML + 스크립트 DSL**로 정의 → 기획자가 코드 없이 이벤트 추가.

### 7.2 이벤트 DSL 예시
```yaml
id: ev_1403_secret_letter
age: [14, 15]
season: autumn
weight: 0.6
conditions:
  - stat.knowledge >= 300
  - personality.agreeable <= -20     # 반항 성향
  - flag.met_elda == true
text: >
  방 청소를 하다 침대 밑에서 봉인된 편지를 발견했다.
  보낸 이는… 마법탑.
choices:
  - label: "조용히 다시 넣어둔다"
    effects: { trust: +15, flag.respected_privacy: true }
  - label: "읽어본다"
    effects: { trust: -20, knowledge: +10, flag.read_letter: true }
    next: ev_1404_confront
  - label: "아이에게 직접 묻는다"
    check: { stat: persuasion, dc: 200 }
    success: { trust: +25, flag.open_talk: true }
    fail: { trust: -10, stress: +10 }
```

### 7.3 엔딩 결정 (의사코드)
```
score[job] = Σ(stat_i × weight_job_i)
           × personalityMultiplier(job, vector)
           × relationGate(job)          # 0 또는 1
           + flagBonus(job)
ending = argmax(score)
if hidden_conditions_met(): ending = hidden
```
- 가중치 테이블은 외부 CSV. **밸런스 시뮬레이터**(헤드리스 10,000회 랜덤 플레이)로 엔딩 분포가 특정 직업에 30% 이상 몰리지 않도록 조정.

### 7.4 세이브 & 데이터
- 월 단위 오토세이브 + 수동 슬롯 10개. 저장 데이터는 **전체 선택 로그 포함**(엔딩 대사 생성·성격 지도용).
