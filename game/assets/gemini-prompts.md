# 제미나이(Chrome) 이미지 생성 프롬프트 팩 — 「별의 공주」

## 사용법
1. Chrome에서 gemini.google.com 접속 → 이미지 생성 모드.
2. **먼저 §0 스타일 앵커를 한 번 보내고**, 이어서 같은 대화에서 아래 프롬프트를 하나씩 보냅니다. (같은 대화 안에서 "같은 캐릭터로" 지시가 잘 유지됩니다.)
3. 결과를 다운로드 → `game/assets/<경로>.png` 이름으로 저장. 크기는 `README.md` 참고.
4. 마음에 안 들면 "같은 구도, 머리 길이만 조금 더 길게"처럼 **차이만** 말해서 재생성.

> 팁: 캐릭터 일관성을 위해 §1-0 '캐릭터 시트'를 먼저 만들고, 이후 모든 캐릭터 프롬프트 앞에 "위 캐릭터 시트의 루나와 동일 인물로"를 붙이세요.

---

## §0. 스타일 앵커 (대화 첫 메시지)

```
앞으로 이 대화에서 만드는 모든 그림은 다음 스타일을 유지해줘.
- 2D 손그림 질감 일러스트, 수채+과슈 느낌의 부드러운 채색, 가는 잉크 선.
- 레퍼런스 분위기: 프린세스메이커 2의 캐릭터 밀도 × 스피릿페어러의 따뜻함 × 디스코 엘리시움의 채색감.
- 팔레트: 보랏빛 남색 밤하늘(#1d1631), 따뜻한 금색(#e7c36a), 상아색 피부, 은발.
- 세계관: 세 개의 달이 뜨는 중세 판타지 왕국 '셀레스티아'. 왕도(귀족), 항구도시(상업), 농촌 평원(마법·생활).
- 12세 이용가. 선정성·과도한 폭력 없음.
- 텍스트·로고·워터마크 넣지 말 것.
```

## §1. 아이(루나) 초상 — `char/` 20장

### §1-0. 캐릭터 시트 (저장 불필요, 일관성용)
```
'루나' 캐릭터 시트. 은발(긴 생머리, 앞머리 있음), 보라색 눈, 상아색 피부, 작은 별 모양 머리핀.
10세·13세·15세·17세 네 가지 나이의 정면 전신을 한 장에 나란히. 중립 표정, 단순한 흰 원피스. 밝은 회색 배경.
```

### 공통 규격
- 세로 3:4, 상반신~허리, 정면 약간 3/4 각도, 단색 어두운 남보라 배경(#1d1631) 또는 투명.
- `{stage}` 나이: child=10세, girl=12세, teen=14세, youth=16세, adult=18세.
- `{cat}` 복장·분위기:
  - **body(신체)**: 가죽 트레이닝 튜닉, 팔 보호대, 목검 또는 진검을 어깨에, 당당한 자세, 햇볕에 탄 뺨, 자신감 있는 미소.
  - **mind(지성)**: 남색 학자 로브, 손에 두꺼운 책, 안경은 없음, 한 손 끝에 작은 보라색 마법 불꽃, 차분하고 지적인 눈.
  - **social(사교)**: 금색 자수가 들어간 드레스, 머리를 올려 묶음, 진주 귀걸이, 우아한 자세, 부드러운 미소.
  - **inner(내면)**: 소박한 녹색 로브, 목에 작은 금 펜던트, 손에 약초 다발 또는 류트, 평온한 표정, 뒤에 은은한 빛.

### 프롬프트 템플릿 (20회 반복)
